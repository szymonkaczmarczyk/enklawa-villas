Enklawa Villas: dokumentacja techniczna

Statyczna strona agencji rezydencji off-market: strona główna z intro i scrollytellingiem, portfolio ośmiu rezydencji z podstronami, okno zapytania, strony prawne. Dwa języki: PL pod /, EN pod /en/.
Strona nie ma API ani backendu. Ta dokumentacja opisuje trasy, model danych, skrypty mediów, komponenty i testy.

Architektura i stack

Astro buduje wszystkie strony do statycznego HTML w dist/. JavaScript w przeglądarce to jeden pakiet (GSAP, Lenis i skrypty strony) oraz mały skrypt podstrony rezydencji.

Strona nie zapisuje cookies ani danych w localStorage i sessionStorage i nie ładuje zasobów z zewnątrz. Dlatego nie ma banera zgody. Pilnuje tego test „strona nic nie zapisuje w przeglądarce”.

Karty portfolio

Kliknięcie w kartę prowadzi na podstronę rezydencji (warstwa a.card__overlay, jedyny link karty, nazwany przez aria-labelledby nagłówkiem). Przycisk „Zapytaj o obiekt” leży nad nią i otwiera okno zapytania z kontekstem obiektu. Podgląd wideo gra po najechaniu (kursor) albo raz, gdy karta jest w 60% w kadrze (dotyk). Slider „Więcej z portfolio” przewija się strzałkami, gestem i przeciąganiem myszą (próg 6 px, kliknięcie po przeciągnięciu jest ignorowane).

Komponent Button

src/components/Button.astro. Renderuje <a>, gdy podano href, inaczej <button type="button">. Pozostałe atrybuty (np. data-dossier-open, aria-label) trafiają na element.

Właściwości

WłaściwośćDomyślnieOpis
variantline Wygląd
WartośćZnaczenie
solidTrawertyn, przy najechaniu wypełnienie dębowe. Główna akcja na ciemnym tle
lineCienka ramka, wypełnienie trawertynem. Akcje drugorzędne
glassMrożone szkło nad zdjęciem lub filmem (nagłówek, hero)
iconarrowRightIkona w kwadratowej komórce. Strzałki dostają animację przejazdu
iconFirstfalseKomórka ikony po lewej (przyciski „Wróć”)
compactfalseWysokość 44 px zamiast 56 px
hrefZamienia przycisk w link

Przykład

<Button variant="glass" data-dossier-open>{t.cta}</Button>
<Button icon="arrowLeft" iconFirst data-dossier-back>{d.back}</Button>
<Button icon="arrowRight" aria-label={t.portfolio.next} data-slider-next />

Przycisk bez treści jest kwadratem (strzałki slidera) i wymaga aria-label. Element z atrybutem data-button-scope (karta) włącza stan najechania przycisku w środku.

Wewnątrz przycisków i kafelków z ramką nie ma animacji transform. Przy ułamkowych pozycjach przeglądarka przenosiła fragment na osobną warstwę i obcinała górną albo dolną krawędź. Wypełnienie animuje height, strzałka left, a wciśnięcie wypełnia przycisk zamiast go zmniejszać.

Nowa rezydencja krok po kroku

  1. Wrzuć film do videos/ i dopisz go do scripts/clips.mjs (name, source, start).
  2. Uruchom npm run previews i npm run residences.
  3. Dodaj wpis w src/data/properties.ts (nazwa, lokalizacja, alt, placement, cena).
  4. Dodaj opis i alt kadrów w src/data/residences.ts.
  5. Dopisz id do listy w tests/e2e/residences.spec.ts i zmień liczbę adresów w teście sitemapy.
  6. npm run test:e2e.

Po regeneracji mediów sprawdź kopie iCloud: find . -name '* [0-9]*.*' -not -path './node_modules/*'.

Testy e2e

npm run test:e2e

Playwright buduje stronę, uruchamia astro preview --ignore-lock na porcie 4332 i przechodzi 32 testy. Flaga --ignore-lock jest potrzebna, bo Astro 7 po wykryciu agenta AI odpala podgląd w tle i Playwright uznaje, że serwer padł.
